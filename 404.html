ENGINEERING WORKSPACE

เครื่องมือวิศวกรรมที่เชื่อมข้อมูลต้นทางกับชุดผลคำนวณ

นายช่างใหญ่ Civil Apps รวมพื้นที่ทำงานสำหรับสร้างแปลน กำหนดโหลด วิเคราะห์ ตรวจออกแบบชิ้นส่วน จัดทำรายงาน และประสานเอกสารโครงการ ผู้ใช้เลือกเครื่องมือจากชนิดงานและหลักฐานที่ต้องการตรวจ ไม่ใช่จากชื่อโปรแกรมเพียงอย่างเดียว

เครื่องมือคอนกรีตที่รองรับใช้ Calculation Snapshot เพื่อให้ Demand, Capacity, หน้าตัด, เหล็ก, ภาพ 3D และรายงานอ้างอิงข้อมูล Run ชุดเดียวกัน รายการที่ยังไม่ประเมินจะแสดง NOT EVALUATED หรือสถานะ Review แยกจากผลที่ตรวจแล้ว

เลือกเครื่องมือตามงานที่ต้องทำ

คานและคานยื่นคอนกรีต

เตรียม span, support, material และ load แล้วอ่าน reaction, shear, moment ผลดัด ผลเฉือน เหล็ก และหลักฐานตามโหมด Analysis ที่เลือก

เสาคอนกรีต

ตรวจแรงอัด โมเมนต์ P-M แยกแกน X/Y, biaxial interaction, หน้าตัด เหล็กปลอก และ 3D cage จากชุดข้อมูลเดียวกัน

พื้นวางบนดิน

SL-04 ใช้คัดกรองเหล็กควบคุมรอยร้าวและจัด Plan, Section, 3D, BOM และ A4 โดยกำลังรับน้ำหนักโครงสร้างยังเป็น NOT EVALUATED

ฐานราก

มีคู่มือฐานรากแผ่ ฐานรากหนึ่งเสาเข็ม และฐานรากเยื้องศูนย์ แต่ละโมดูลมี input ชุดตรวจและขอบเขตหลักฐานของตนเอง

ระบบไฟฟ้าและสุขาภิบาล

จัดโหลด สาย เบรกเกอร์ Load Schedule หรือวางแนวท่อน้ำดี น้ำเสีย และส่งออก CAD ภายในขอบเขตที่ระบุบนเครื่องมือ

BOQ เอกสาร และบริหารโครงการ

ถอดปริมาณให้ย้อนกลับถึงแบบ รวม PDF ตรวจ Defect และติดตาม WBS, Gantt, progress, cost, SPI, CPI และ S-Curve

ลำดับตรวจที่ช่วยลดข้อมูลผิดชุด

1. ยืนยันข้อมูลต้นทาง

ตรวจ geometry, material, support, load, reinforcement, หน่วย และ revision ให้ตรงกับโครงการก่อน Run

2. อ่านผลพร้อมขอบเขต

แยกผลที่ประเมินแล้วออกจาก Beta, Review, NOT EVALUATED และ HOLD_OWNER_PE โดยไม่ตีความสถานะเหล่านี้เป็น PASS

3. เทียบผลข้ามหน้าจอ

ตรวจว่าหน้าจอหลัก Section, 3D, A4, Calculation Book, Drawing และ DXF อ้างอิง Snapshot และ revision เดียวกันในโมดูลที่รองรับ

4. ให้ผู้รับผิดชอบตรวจ

ผลและเอกสารจากเว็บเป็นหลักฐานสำหรับทบทวน ไม่ใช่การรับรองแบบก่อสร้าง ต้องผ่านการตรวจและลงนามตามวิชาชีพและขอบเขตโครงการ

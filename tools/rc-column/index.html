ลำดับการตรวจเสาคอนกรีต

เครื่องมือแยกข้อมูลต้นทางออกจากผล interaction และรายงานอย่างชัดเจน เพื่อให้ผู้ใช้เห็นว่าค่าใดเป็น input ค่าใดเป็นผลจาก engine และค่าใดเป็นเพียงข้อมูลอ้างอิง

Input

กำหนดขนาดเสา ความยาว วัสดุ reinforcement arrangement และแรง Pu, Mx, My ตามกรณีที่ต้องตรวจ

Run P-M-M

ระบบคำนวณ interaction ตาม method ที่รองรับ และเก็บผลแกน X/Y กับ biaxial utilization

Snapshot

verdict, D/C, curves, Section/Rebar, slenderness screen และ trace ถูกตรึงในหลักฐานชุดเดียว

A4 Evidence

รายงานรวม P-M สองแกน หน้าตัด เหล็ก กำลัง ขอบเขต และ fingerprint สำหรับ review

หน้าจอช่วยตอบคำถามอะไร

แรงอัดร่วมกับโมเมนต์

ผู้ใช้เห็นตำแหน่ง demand เทียบกับ interaction evidence แยกแกน X/Y และผล biaxial ที่ engine ออกจริง

หน้าตัดและการจัดเหล็ก

จำนวนและตำแหน่งเหล็กหลัก เหล็กปลอก และ 3D cage ใช้ geometry จาก snapshot เพื่อให้ภาพตรงกับ arrangement ที่ตรวจ

Quick Design หรือ Check Existing

Quick Design ใช้ catalog ที่ควบคุมได้ ส่วน Check Existing เหมาะกับการป้อนหน้าตัดและเหล็กที่มีอยู่เพื่อดูผลภายในขอบเขตโมดูล

Strength กับ slenderness ไม่ใช่ค่าเดียวกัน

รายงานแยก Strength D/C ออกจาก conservative slenderness screen และไม่เปลี่ยนข้อมูลอ้างอิงให้เป็น PASS โดยอัตโนมัติ

หลักฐาน P-M ที่ควรอ่านให้ครบ

หลักฐานใช้ตอบคำถามข้อควรระวัง
P-M แกน X/Yดูความสัมพันธ์กำลังรับแรงอัดและโมเมนต์ในแต่ละแกนsampled curve เป็นหลักฐานอ้างอิงตาม snapshot ไม่ควรถูกใช้แทน exact fiber analysis ที่ engine ไม่ได้ออก
Biaxial interactionดู utilization เมื่อแรงกระทำสองแกนพร้อมกันmethod reciprocal และ contour มีชนิดหลักฐานต่างกัน ต้องอ่าน scalar capacity ตามที่ snapshot มีจริง
Section/Rebarยืนยัน geometry และ arrangement ที่ถูกตรวจภาพ geometry ไม่ได้ยืนยัน anchorage, splice, joint หรือ seismic detailing หากโมดูลไม่ได้ประเมิน

รายการที่รายงานต้องไม่ทำให้เข้าใจว่าได้รับการประเมินแล้ว

  • ที่มาของ load combination และ minimum eccentricity เมื่อไม่มีหลักฐานจาก engine
  • second-order effect, sway, P-Δ, P-δ หรือ magnification ที่โมดูลยังไม่รองรับครบ
  • exact coordinate/fiber P-M และ clause applicability ที่ไม่ได้ออกใน Snapshot
  • development, splice, hook, joint, seismic และ durability detailing
  • crosstie หรือรายละเอียดก่อสร้างที่ยังระบุว่าไม่ได้ประเมิน
รายงานใช้เพื่อ review ภายในขอบเขตของ Snapshot ค่า PASS ใน strength check ไม่ได้เลื่อนรายการที่ยังไม่ได้ประเมินให้เป็น OK และไม่เปลี่ยนรายงานเป็นแบบพร้อมก่อสร้าง

คู่มือที่เกี่ยวข้อง

เลือกโปรแกรมโครงสร้าง ออกแบบคานคอนกรีต ออกแบบฐานราก Calculation Snapshot และ A4

ข้อมูลหน้านี้อธิบายขอบเขตของ Concrete Column Workbench ตามสถานะที่เผยแพร่ ผลคำนวณต้องผ่านการตรวจโดยผู้รับผิดชอบก่อนนำไปใช้กับงานจริง

วิธีเลือกเครื่องมือก่อนเริ่มคำนวณ

งานทั้งอาคาร งานตรวจชิ้นส่วน และงานประเมินอาคารเดิมต้องการข้อมูลต้นทางต่างกัน การเลือกโมดูลให้ถูกช่วยลดการป้อนข้อมูลซ้ำและทำให้ผลลัพธ์ย้อนกลับไปยังสมมติฐานเดิมได้

ระบุชนิดงาน

เลือกว่ากำลังสร้างแบบอาคารใหม่ ตรวจอาคารเดิม หรือตรวจชิ้นส่วนคาน เสา หรือฐานรากโดยตรง

เตรียมข้อมูลต้นทาง

รวบรวม geometry, material, support, load และ reinforcement ที่ต้องใช้จริงในโมดูลนั้น

Run Analysis

เครื่องมือ Concrete ที่รองรับจะสร้าง Calculation Snapshot เพื่อยึดผล Demand, Capacity และ trace ชุดเดียวกัน

อ่านขอบเขตก่อนส่งงาน

ตรวจรายการที่ประเมินแล้ว รายการอ้างอิง และรายการที่ยังไม่ได้ประเมินก่อนใช้ผลในการตัดสินใจ

เครื่องมือหลักแยกตามคำถามทางวิศวกรรม

งานอาคารใหม่

เหมาะเมื่อเริ่มจากแปลนอาคาร ต้องกำหนดโหลดและติดตาม load path ไปยังคาน เสา พื้น และฐานรากใน workspace เดียว

ประเมินอาคารเดิม

ใช้เมื่อข้อมูลมาจากการสำรวจหรือ as-built และต้องแยก capacity เดิมออกจากข้อเสนอการใช้งานหรือการต่อเติม

คานคอนกรีต

ตรวจ load, reaction, FBD/SFD/BMD ในโหมดที่รองรับ ผลดัดและเฉือน เหล็กควบคุม 3D และรายงานจาก Snapshot เดียว

เสาคอนกรีต

ตรวจแรงอัดและโมเมนต์ด้วย P-M แยกแกน X/Y, biaxial interaction, หน้าตัด เหล็กปลอก 3D cage และรายงาน A4

ฐานราก

มีทั้งฐานรากเยื้องศูนย์และฐานรากหนึ่งเสาเข็ม แต่ละเครื่องมือมีชุดตรวจและขอบเขตหลักฐานของตนเอง

พื้นวางบนดิน

SL-04 ใช้คัดกรองเหล็กควบคุมรอยร้าวและจัดชุดผลคำนวณ โดย Structural load ยัง NOT EVALUATED และ Drawing/DXF คง HOLD_OWNER_PE

ฐานรากแผ่

ตรวจ bearing, kern, flexure, one-way shear และ punching พร้อม Section, 3D, A4 และ Calculation Book จาก Snapshot เดียว

คานยื่นคอนกรีต

เตรียมระบบรองรับและโหลดให้ถูกทิศทาง แล้วตรวจโมเมนต์ลบ เหล็กบน ระยะฝังยึด แรงเฉือน การโก่ง และรอยร้าว

ถอดปริมาณและ BOQ

เชื่อมตัวเลขกลับไปยังแบบ ตำแหน่ง สูตร หน่วย สมมติฐาน และ revision เพื่อให้ผู้ถอดกับผู้ตรวจใช้หลักฐานชุดเดียวกัน

เครื่องมือที่อยู่ระหว่างพัฒนา

สถานะ Beta หรือ Engineering Review จะระบุบนการ์ดและรายงาน การมองเห็นเครื่องมือไม่เท่ากับการอนุมัติแบบก่อสร้าง

สิ่งที่ควรตรวจในผลลัพธ์ทุกครั้ง

หน้าจอที่อ่านง่ายไม่ได้แทนการตรวจสมมติฐานและขอบเขตวิธีคำนวณ โดยเฉพาะงานที่มีผลต่อความปลอดภัย

  • หน่วย, geometry, material และ load ตรงกับข้อมูลโครงการ
  • ผล Demand/Capacity และ verdict มาจาก Snapshot ล่าสุด ไม่ใช่ผลเก่าหลังแก้ input
  • หน้าตัดและเหล็กที่แสดงเป็นชุดเดียวกับที่ engine ตรวจ
  • รายการ NOT EVALUATED หรือ Engineering Review ไม่ถูกตีความเป็น PASS
  • รายงานและแบบที่ใช้ส่งงานผ่านการตรวจและลงนามโดยผู้มีหน้าที่รับผิดชอบ
หลักการของนายช่างใหญ่ ทุก verdict ควรย้อนกลับไปยัง input, วิธีคำนวณ และหลักฐานที่ออกจาก Calculation Snapshot เดียวกัน อ่านรายละเอียดที่หน้า หลักฐานผลคำนวณและขอบเขตการใช้งาน

อ่านคู่มือเฉพาะเครื่องมือ

ออกแบบคานคอนกรีต ออกแบบเสาคอนกรีต ออกแบบฐานราก พื้นวางบนดิน ฐานรากแผ่ ฐานราก 1 เสาเข็ม คานยื่นคอนกรีต ถอดปริมาณและ BOQ ตรวจ Defect Project Plan คำนวณไฟฟ้า สุขาภิบาล รวม PDF BOQ งานบิ้วอิน BOQ สอบย้อน Calculation Snapshot และ A4

นายช่างใหญ่ Civil Apps เป็นพื้นที่ทำงานวิศวกรรมบนเว็บ ผลจากเครื่องมือต้องใช้ภายในขอบเขตที่ระบุและผ่านการตรวจโดยผู้รับผิดชอบก่อนนำไปใช้กับงานจริง

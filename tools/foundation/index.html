ฐานรากสองชนิดตอบคำถามต่างกัน

เครื่องมือเหมาะกับหลักฐานที่เด่น
ฐานรากเยื้องศูนย์กรณีที่ตำแหน่งเสา แนวแรง หรือ geometry ทำให้เกิด eccentricity และต้องติดตาม reaction กับ momentPile reaction trace, punching, beam shear, plan, section และ report ตามขอบเขตโมดูล
ฐานรากหนึ่งเสาเข็มฐานหัวเสาเข็มเดี่ยวที่ต้องตรวจ load ต่อเสาเข็มและกลไกภายใน pile capSafe Load, punching, D-region, dowel, reinforcement, แบบ 2D/3D และรายงาน

ลำดับข้อมูลที่ควรเตรียม

Geometry

ตำแหน่งเสา ฐาน เสาเข็ม ขนาดหน้าตัด ระยะขอบ ระยะเยื้อง และระดับที่เกี่ยวข้อง

Material

กำลังคอนกรีต เหล็กเสริม ขนาดเสาเข็ม และค่าที่มาจากข้อมูลผลิตภัณฑ์หรือผลทดสอบ

Demand

แรงอัด โมเมนต์ แรงเฉือน และ load combination ที่มีที่มาชัดเจนจากโครงการ

Evidence

ตรวจ reaction, capacity, D/C, geometry, reinforcement, limitation และรายงานจากผลล่าสุด

หลักฐานสำคัญของฐานรากหนึ่งเสาเข็ม

Safe Load

เปรียบเทียบ demand กับค่ารับน้ำหนักที่ผู้ใช้กำหนดจากข้อมูลเสาเข็ม การเลือกค่าต้องมีแหล่งอ้างอิงที่เหมาะกับหน้างาน

Punching และ D-region

แยกกลไกที่ต้องตรวจภายใน pile cap พร้อม operands และสถานะ ไม่สรุปจากภาพ 3D เพียงอย่างเดียว

Dowel และเหล็กเสริม

แสดงรายละเอียดที่ engine ออกและ geometry ที่สอดคล้องกับผล เพื่อให้ย้อนตรวจจากตารางไปยังรูปได้

ข้อมูลดินและเสาเข็มยังเป็นความรับผิดชอบของโครงการ

ค่า Safe Load, settlement, installation condition และข้อมูลชั้นดินไม่ควรถูกเดาจากประเภทฐานรากหรือภาพประกอบ

สิ่งที่เครื่องมือฐานรากไม่ควรถูกใช้กล่าวอ้าง

  • ไม่ควรเรียกว่าออกแบบฐานรากทุกชนิด เพราะฐานรากแผ่และรูปแบบอื่นมี lifecycle และ engine ต่างกัน
  • ไม่ควรใช้ค่า Safe Load ที่ไม่มีผลทดสอบหรือข้อมูลผู้ผลิตรองรับ
  • ไม่ควรตีความภาพ 2D/3D เป็นแบบก่อสร้างที่อนุมัติแล้ว
  • ไม่ควรซ่อนรายการที่ไม่ได้ประเมิน เช่น settlement, group effect หรือรายละเอียดหน้างาน
  • ผลต้องถูกตรวจร่วมกับ load path ของเสา คานคอดิน ดิน และวิธีติดตั้งเสาเข็ม
เริ่มจาก topology ไม่ใช่เริ่มจากชื่อฐาน ถ้า geometry และ load path ไม่ตรงกับเครื่องมือ ให้กลับไปเลือก workflow ที่รองรับแทนการปรับ input เพื่อบังคับให้ได้ผล

คู่มือที่เกี่ยวข้อง

เลือกโปรแกรมโครงสร้าง ออกแบบคานคอนกรีต ออกแบบเสาคอนกรีต Calculation Snapshot และ A4

ข้อมูลหน้านี้อธิบายเครื่องมือฐานรากสองชนิดที่เผยแพร่ใน Marketplace ไม่ใช่การรับรองฐานรากทุกประเภทหรือการแทนข้อมูลสำรวจดิน

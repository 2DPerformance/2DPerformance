สุขาภิบาลและ Web CAD

เครื่องมือสุขาภิบาลใช้วางแนวท่อน้ำดี น้ำเสีย ถังเก็บน้ำ และบ่อพักบน Web CAD พร้อมส่งออก DXF เพื่อประสานแบบ ตำแหน่งและขนาดที่วางต้องตรวจร่วมกับระดับ ความลาด อัตราการไหล และข้อกำหนดโครงการ

ขั้นตอนใช้งานที่ควรตรวจตามลำดับ

เริ่มจากข้อมูลต้นทางที่ตรวจสอบได้ แล้วค่อยอ่านผลลัพธ์และข้อจำกัดในบริบทของโครงการ

กำหนดจุดใช้งาน

ระบุตำแหน่งสุขภัณฑ์ อุปกรณ์ ถัง และจุดเชื่อมต่อ

วางแนวและระดับ

จัด route ท่อ ขนาด slope และระดับให้ประสานกับโครงสร้าง

ตรวจระบบ

ทบทวน flow, vent, cleanout และการเข้าถึงบำรุงรักษา

ส่งออกเพื่อประสานแบบ

ตรวจ layer หน่วย และตำแหน่งก่อนส่งออก DXF

ข้อมูลที่ต้องเตรียม

  • จุดใช้น้ำและอัตราการใช้งาน
  • ตำแหน่งถัง ปั๊ม บ่อพัก และจุดระบาย
  • ขนาดท่อ ระดับ ความลาด และวัสดุ
  • ข้อกำหนดระบบ vent, cleanout และมาตรฐานโครงการ

ผลลัพธ์ที่ใช้ตรวจทานได้

  • ผังแนวท่อน้ำดีและน้ำเสียบน Web CAD
  • ตำแหน่งถังและบ่อพักสำหรับประสานงาน
  • ข้อมูลชั้นแบบและรายการสำหรับตรวจ
  • ไฟล์ DXF ตาม geometry ที่วาง

ขอบเขตและข้อจำกัดก่อนใช้ผล

  • Hydraulic Design ยัง NOT EVALUATED ตามข้อความกำกับเครื่องมือ
  • ต้องตรวจระดับจริงและการชนกับโครงสร้างหรือระบบอื่น
  • DXF เป็นข้อมูลประสานแบบ ไม่ใช่การอนุมัติงานติดตั้ง
  • ผู้รับผิดชอบต้องตรวจขนาดท่อ flow vent และมาตรฐานก่อนใช้งาน
หลักฐานไม่ใช่การอนุมัติ ผลและเอกสารจากระบบต้องผ่านการตรวจโดยผู้รับผิดชอบตามวิชาชีพและขอบเขตโครงการก่อนนำไปตัดสินใจหรือใช้ก่อสร้าง

คู่มือที่เกี่ยวข้อง

คู่มือเครื่องมือทั้งหมดพื้นวางบนดิน SL-04ฐานรากแผ่ FT-03ฐานราก 1 เสาเข็ม FT-02คานยื่นคอนกรีตหลักฐานผลคำนวณ

นายช่างใหญ่ Civil Apps เป็นพื้นที่ทำงานวิศวกรรมบนเว็บ ผลจากเครื่องมือต้องใช้ภายในขอบเขตที่ระบุและผ่านการตรวจโดยผู้รับผิดชอบก่อนนำไปใช้กับงานจริง

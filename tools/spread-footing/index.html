FT-03 จัดลำดับการตรวจฐานรากแผ่ตั้งแต่แรงดันดินและ kern ไปถึง flexure, one-way shear และ punching พร้อม Section, 3D, A4, Calculation Book และ Drawing Pack ที่อ้างอิง Calculation Snapshot เดียวกัน

ขั้นตอนใช้งานที่ควรตรวจตามลำดับ

เริ่มจากข้อมูลต้นทางที่ตรวจสอบได้ แล้วค่อยอ่านผลลัพธ์และข้อจำกัดในบริบทของโครงการ

กำหนด Geometry

ระบุฐาน ตอม่อ ระดับ และตำแหน่งแรงให้ตรงกับโมเดล

กรอกดิน วัสดุ และแรง

ใช้ค่าที่มีที่มาและหน่วยชัดเจนสำหรับ load combination ที่ตรวจ

Run Flow 01–08

อ่าน bearing, kern, flexure, one-way shear และ punching ตามลำดับ

เทียบหลักฐาน

ตรวจ Section, 3D, A4, Calculation Book และชุดแบบว่าใช้ Snapshot เดียวกัน

ข้อมูลที่ต้องเตรียม

  • ขนาดฐานและตอม่อ ระดับ และ cover
  • แรงกด โมเมนต์ และ load combination
  • กำลังคอนกรีต เหล็กเสริม และคุณสมบัติดิน
  • เหล็กที่เลือกและข้อกำหนดรายละเอียด

ผลลัพธ์ที่ใช้ตรวจทานได้

  • แรงดันดินและการตรวจ kern
  • ผลดัด แรงเฉือนทางเดียว และแรงเฉือนทะลุ
  • Section และ 3D สำหรับตรวจการจัดวาง
  • A4, Calculation Book และ Drawing Pack จาก Snapshot เดียว

ขอบเขตและข้อจำกัดก่อนใช้ผล

  • Owner ตรวจรูปแบบการนำเสนอและหลักฐาน ไม่ใช่อนุมัติแบบก่อสร้าง
  • ค่ากำลังรับน้ำหนักดินต้องมาจากข้อมูลโครงการที่รับผิดชอบได้
  • ผลคำนวณไม่แทนการตรวจ settlement และ load path ทั้งระบบ
  • Drawing และ DXF ต้องคง HOLD_OWNER_PE จนผู้รับผิดชอบตรวจและลงนาม
หลักฐานไม่ใช่การอนุมัติ ผลและเอกสารจากระบบต้องผ่านการตรวจโดยผู้รับผิดชอบตามวิชาชีพและขอบเขตโครงการก่อนนำไปตัดสินใจหรือใช้ก่อสร้าง

คู่มือที่เกี่ยวข้อง

คู่มือเครื่องมือทั้งหมดพื้นวางบนดิน SL-04ฐานราก 1 เสาเข็ม FT-02คานยื่นคอนกรีตถอดปริมาณและ BOQหลักฐานผลคำนวณ

นายช่างใหญ่ Civil Apps เป็นพื้นที่ทำงานวิศวกรรมบนเว็บ ผลจากเครื่องมือต้องใช้ภายในขอบเขตที่ระบุและผ่านการตรวจโดยผู้รับผิดชอบก่อนนำไปใช้กับงานจริง

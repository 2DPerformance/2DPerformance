Run Analysis

อ่าน reaction, shear และ moment พร้อมตรวจว่า diagram สอดคล้องกับคานยื่น

ตรวจเหล็กและรายละเอียด

ทบทวนเหล็กบน ระยะฝัง จุดตัดเหล็ก การโก่ง และรอยร้าว

ข้อมูลที่ต้องเตรียม

  • ช่วงยื่นและขนาดหน้าตัด
  • support condition ที่จุดยึด
  • น้ำหนักกระจาย แรงจุด และ load combination
  • วัสดุ cover และเหล็กที่ต้องการตรวจ

ผลลัพธ์ที่ใช้ตรวจทานได้

  • reaction, shear และ moment ตามโหมด Analysis
  • ผลตรวจดัดและเฉือนตาม Snapshot
  • หน้าตัดและ 3D rebar สำหรับตรวจทาน
  • A4 ที่อ้างอิง input และผล Run เดียวกัน

ขอบเขตและข้อจำกัดก่อนใช้ผล

  • ต้องตรวจความแข็งและกำลังของจุดยึดกับสมาชิกหลักแยกจากตัวคาน
  • ต้องตรวจ serviceability การโก่งและรอยร้าวตามเกณฑ์โครงการ
  • Direct mode ไม่สร้าง FBD หรือรูปโก่งเกินข้อมูลแรงที่ป้อน
  • แบบเหล็กต้องคง HOLD_OWNER_PE จนตรวจ anchorage และลงนาม
หลักฐานไม่ใช่การอนุมัติ ผลและเอกสารจากระบบต้องผ่านการตรวจโดยผู้รับผิดชอบตามวิชาชีพและขอบเขตโครงการก่อนนำไปตัดสินใจหรือใช้ก่อสร้าง

คู่มือที่เกี่ยวข้อง

คู่มือเครื่องมือทั้งหมดพื้นวางบนดิน SL-04ฐานรากแผ่ FT-03ฐานราก 1 เสาเข็ม FT-02ถอดปริมาณและ BOQหลักฐานผลคำนวณ

นายช่างใหญ่ Civil Apps เป็นพื้นที่ทำงานวิศวกรรมบนเว็บ ผลจากเครื่องมือต้องใช้ภายในขอบเขตที่ระบุและผ่านการตรวจโดยผู้รับผิดชอบก่อนนำไปใช้กับงานจริง

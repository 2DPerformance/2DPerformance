ฐานราก 1 เสาเข็ม FT-02

FT-02 เปิด F1 Engine เดิมใน Mother-card สำหรับตรวจ Safe Load, punching, D-region, dowel และเหล็กจาก Input ชุดเดียว พร้อมแปลน รูปตัด 3D และรายงาน A4 โดยแบบและรายงานยังต้องผ่านการตรวจของผู้รับผิดชอบก่อนนำไปใช้กับงานจริง

ขั้นตอนใช้งานที่ควรตรวจตามลำดับ

เริ่มจากข้อมูลต้นทางที่ตรวจสอบได้ แล้วค่อยอ่านผลลัพธ์และข้อจำกัดในบริบทของโครงการ

กำหนดเสาเข็มและฐาน

ระบุขนาด ตำแหน่ง ระดับ และเงื่อนไขรองรับ

กรอกแรงและวัสดุ

ใช้แรงที่ส่งมาจาก load path พร้อมกำลังคอนกรีตและเหล็ก

ตรวจกลไกสำคัญ

อ่าน Safe Load, punching, D-region และ dowel แยกกัน

ทบทวนรายละเอียด

เทียบผลคำนวณกับแปลน รูปตัด 3D และรายงาน

ข้อมูลที่ต้องเตรียม

  • แรงกดและโมเมนต์ที่ฐาน
  • Safe Load และข้อมูลเสาเข็มที่มีเอกสารอ้างอิง
  • Geometry ฐาน ตอม่อ และระดับตัด punching
  • วัสดุ cover dowel และเหล็กฐาน

ผลลัพธ์ที่ใช้ตรวจทานได้

  • ผลตรวจ Safe Load และ punching
  • ผล D-region และ dowel ตามขอบเขตโมดูล
  • เหล็กฐานพร้อมภาพ 2D และ 3D
  • รายงานสำหรับตรวจทานจากข้อมูลชุดเดียว

ขอบเขตและข้อจำกัดก่อนใช้ผล

  • ต้องตรวจข้อมูลเสาเข็มจากผู้ผลิตหรือผลทดสอบที่ใช้กับโครงการจริง
  • ผลโมดูลไม่แทนการตรวจกลุ่มเสาเข็ม การทรุดตัว หรือผลกระทบจากดินทั้งหมด
  • รายละเอียดเหล็กต้องตรวจระยะหุ้ม ระยะห่าง และการยึดเหนี่ยวหน้างาน
  • ชุดแบบและ DXF ต้องอยู่ที่ HOLD_OWNER_PE ก่อนนำไปใช้ก่อสร้าง
หลักฐานไม่ใช่การอนุมัติ ผลและเอกสารจากระบบต้องผ่านการตรวจโดยผู้รับผิดชอบตามวิชาชีพและขอบเขตโครงการก่อนนำไปตัดสินใจหรือใช้ก่อสร้าง

คู่มือที่เกี่ยวข้อง

คู่มือเครื่องมือทั้งหมดพื้นวางบนดิน SL-04ฐานรากแผ่ FT-03คานยื่นคอนกรีตถอดปริมาณและ BOQหลักฐานผลคำนวณ

นายช่างใหญ่ Civil Apps เป็นพื้นที่ทำงานวิศวกรรมบนเว็บ ผลจากเครื่องมือต้องใช้ภายในขอบเขตที่ระบุและผ่านการตรวจโดยผู้รับผิดชอบก่อนนำไปใช้กับงานจริง

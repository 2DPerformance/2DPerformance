BM-01 · RC BEAM WORKBENCH

โปรแกรมออกแบบคานคอนกรีตที่ตามผลจากแรงไปถึงเหล็กและรายงาน

Concrete Beam Workbench รับ geometry, support และ material แล้วให้เลือกกรอกน้ำหนักบนคาน หรือกรอก Design envelope จากโมเดลวิเคราะห์ เมื่อ Run Analysis ระบบยึดผล Demand, Capacity, Section/Rebar และ A4 ไว้ใน Calculation Snapshot ชุดเดียว

ลำดับการทำงานของเครื่องมือคาน

หน้าจอจัดลำดับให้ผู้ใช้ตัดสินใจ input ต้นทางก่อน แล้วจึงสร้างผลที่อ่านร่วมกันทุกมุมมอง การแก้ input หลัง Run ทำให้ผลเก่าเป็น stale และต้องวิเคราะห์ใหม่

Input

กำหนดหน้าตัด ช่วงคาน support และวัสดุ แล้วเลือกกรอกน้ำหนัก หรือกรอกแรงจาก Analysis ที่รวม load combination มาแล้ว

Run Analysis

โหมดกรอกน้ำหนักวิเคราะห์ reaction และแรงภายใน ส่วน Direct mode ใช้ envelope ที่ผู้ใช้รับรองโดยไม่คูณ combination ซ้ำ

Snapshot

ผลดัด เฉือน demand/capacity หน้าตัด เหล็ก และ trace ถูกตรึงใน snapshot เดียว

A4 Evidence

รายงานสรุป analysis, strength, detailing, serviceability, limitations และ fingerprint สำหรับย้อนตรวจ

ผลที่ใช้ตรวจพฤติกรรมคาน

แรงและแผนภาพ

โหมดที่มี load model ครบจะแสดง Free Body Diagram, reaction, Shear Force Diagram และ Bending Moment Diagram ให้เห็นทิศทางและตำแหน่ง governing

กำลังดัดและแรงเฉือน

แสดง Demand, Capacity, อัตราส่วนการใช้งาน และ verdict พร้อม operands ที่นำไปสู่ผล ไม่ใช้สีเพียงอย่างเดียว

หน้าตัดและเหล็ก 3D

ภาพหน้าตัด เหล็กหลัก และเหล็กปลอกอ่านจาก arrangement เดียวกับที่เครื่องมือตรวจ เพื่อหลีกเลี่ยงภาพสวยที่ไม่ตรงกับผลคำนวณ

Direct mode ไม่สร้างหลักฐานเกิน input

เมื่อผู้ใช้ป้อนแรงภายในโดยตรง ระบบไม่ควรสร้าง FBD หรือรูปโก่งจากสมมติฐานที่ไม่มีในข้อมูลต้นทาง

กรอกน้ำหนักกับกรอกแรงจาก Analysis ต่างกันอย่างไร

โหมดเหมาะกับสิ่งที่ผู้ใช้ต้องยืนยัน
กรอกน้ำหนักเริ่มจาก Dead load, Live load และแรงจุดที่รองรับ เพื่อให้ระบบรวมแรงและสร้าง reaction, FBD, SFD และ BMDload path, support, ตำแหน่งแรง, design method และหน่วย
กรอกแรงจาก Analysisรับโมเมนต์บวก โมเมนต์ลบ และแรงเฉือนจาก design envelope ของโมเดลวิเคราะห์ภายนอกload combination ถูกใช้มาแล้ว ค่าครอบคลุม governing cases และไม่ต้องให้ระบบสร้างแผนภาพแรงสมมติ

ขอบเขตที่ต้องอ่านก่อนใช้รายงาน

  • เลือกวิธีคำนวณและหน่วยให้ตรงกับ basis ของโครงการ
  • ตรวจว่า Snapshot เป็นผลล่าสุดและไม่อยู่ในสถานะ running หรือ stale
  • อ่านข้อความ NOT EVALUATED และ limitations ใน A4 ให้ครบ
  • ผล FAIL หรือ REVIEW ใช้เปิดหลักฐานเพื่อแก้ input ไม่ใช่ยืนยันแบบก่อสร้าง
  • การพัฒนาเหล็ก รอยต่อ สภาวะหน้างาน และแบบก่อสร้างยังต้องผ่านการตรวจของผู้รับผิดชอบ
รายงาน A4 คือหลักฐานสรุป ไม่ใช่ใบรับรอง รายงานช่วยให้ย้อนจาก verdict ไปยัง Demand, Capacity, operands และ fingerprint ได้ แต่สิทธิ์เปิดเครื่องมือหรือสถานะ PASS ในโมดูลไม่แทนการอนุมัติแบบก่อสร้าง

คู่มือที่เกี่ยวข้อง

เลือกโปรแกรมโครงสร้าง ออกแบบเสาคอนกรีต ออกแบบฐานราก Calculation Snapshot และ A4

ข้อมูลหน้านี้อธิบายขอบเขตของ Concrete Beam Workbench ตามสถานะที่เผยแพร่ ผลคำนวณต้องผ่านการตรวจโดยผู้รับผิดชอบก่อนนำไปใช้กับงานจริง
